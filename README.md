# Ahmad Digital — Portfolio Website

A beginner-friendly responsive digital marketing and web development portfolio built with:

- HTML5
- CSS3
- JavaScript

## Features

- Responsive design
- Home, About, Services, Projects and Contact sections
- Mobile navigation menu
- Working demo contact form interaction
- No external libraries required

## Run locally

Open `index.html` in your browser.

## GitHub Pages

After uploading the project to GitHub:

1. Open your repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and wait for GitHub Pages to publish the site.

## Customize

Replace the name, text, project descriptions and contact details in `index.html` with your own information.
